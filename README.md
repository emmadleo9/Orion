
## Instagram authentication providers

Orion supports three provider modes. The default `token` mode reads `INSTAGRAM_ACCESS_TOKEN` and `INSTAGRAM_USER_ID`. `direct-oauth` is selected automatically when `INSTAGRAM_OAUTH_CLIENT_ID` and `INSTAGRAM_OAUTH_CLIENT_SECRET` are present. Set the exact Meta OAuth redirect URI to `INSTAGRAM_OAUTH_REDIRECT_URI` (default `http://localhost:3000/api/auth/instagram/callback`), start Orion, and open `/api/auth/instagram/login`. Orion keeps the resulting long-lived token in server memory only; it is never returned to the dashboard or written to disk. The server performs the short-lived-to-long-lived exchange with the app secret.

For Manus-hosted connector execution, set `ORION_INSTAGRAM_PROVIDER=connector`, `ORION_CONNECTOR_BRIDGE_URL`, and optionally `ORION_CONNECTOR_BRIDGE_SECRET`. Orion calls the trusted bridge at `/instagram/{operation}` with JSON and expects `{ "result": ... }`. The bridge is the runtime boundary that invokes the authenticated Manus Instagram connector; a standalone Node process cannot call MCP tools or extract their tokens directly. Do not expose the bridge publicly or put a connector token in browser code.

Authentication routes are `GET /api/auth/instagram/status`, `GET /api/auth/instagram/login`, `GET /api/auth/instagram/callback`, and `POST /api/auth/instagram/logout`. Direct Meta OAuth uses the official Instagram Login endpoints documented by Meta: [OAuth authorize](https://developers.facebook.com/documentation/instagram-platform/reference/oauth-authorize), [access-token exchange](https://developers.facebook.com/documentation/instagram-platform/reference/access_token), and [Business Login](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/business-login).
